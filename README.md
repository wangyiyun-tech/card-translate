# Card Translate — 网页自动翻译

源码公开，日常使用免费；商业分发需另行授权。Manifest V3，原生 JavaScript，无需构建。

## 下载与安装

下载仓库中的 `card-translate-1.1.4.zip`（打开该文件后点击下载），解压后在 Chrome / Edge 扩展管理页选择“加载已解压的扩展程序”，选择 `extension` 文件夹。ZIP 中包含完整源码及使用许可证。
卡片浏览器桌面版可在“工具 → 扩展”加载该文件夹，或安装发布的独立扩展 ZIP。

## 功能

英文网页自动翻译为简体中文；按完整段落翻译；视口优先；支持动态网页；缓存及请求去重；可恢复原文；可选自定义翻译服务。

## 隐私与限制

公共翻译模式会把待翻译文字发送到 Google / MyMemory 服务；不会翻译密码、用户输入及可编辑区域。请不要在含敏感资料的网页启用公共翻译。公共接口可能限流或不可达，项目不保证服务永久免费或在线。可用自己的翻译服务替代。
